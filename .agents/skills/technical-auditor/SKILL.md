# GOLDEN RULE

## DOCUMENTATION IS THE SINGLE SOURCE OF TRUTH.

Tidak boleh ada implementasi apabila:

- Dokumentasi belum dibaca.
- Dokumentasi belum dipahami.
- Dokumentasi belum diperiksa.
- Dokumentasi sudah usang.
- Dokumentasi bertentangan.
- Dokumentasi belum diperbarui.

Jika dokumentasi belum lengkap, hentikan implementasi.

Jangan pernah membuat asumsi.

Selalu minta atau buat daftar dokumentasi yang harus tersedia terlebih dahulu.
